# Reusable hero-building workflow

Build on `LandmarkBuilder`, existing authored/retail/skyline dispatch, `ArchitecturalBatch`, the real-place typography atlas and canonical city approval. `heroCraft` contains small repeated modules, not another registry or architecture engine.

1. Inspect actual normal-camera arrival and active dispatch; identify placement, orientation, massing, entrance, context or material cause before modeling.
2. Record official/architect reference, canonical model origin/yaw/footprint, riverbank, neighbors and street access. Distinguish verified fact from arcade compression and unresolved survey details.
3. Keep stable IDs and existing physical parcels. Any exception requires researched canonical data and strict graph/parcel/river/road checks. Terminal's explicit pedestrian apron is this PR's sole spatial correction.
4. Author the silhouette and entrance first; repeat facade floors, curtain walls, supported canopies and planting with bounded shared modules. Avoid invisible detail. MahaNakhon emits exposed voxel faces only, preserving coherent occupancy at both LODs.
5. Use opaque PBR glass/metal/stone finishes, merged/instanced detail and selective existing emissive night materials. No global lighting/post-process replacement, new dynamic-light pass or downloaded textures/models.
6. Place plain correctly oriented names in the existing one-texture atlas. Atlas increases from 1024×1024 to 2048×1024 (+4 MiB raw RGBA; no mip chain) while texture count remains unchanged. No copied logo art or invented real-brand storefronts.
7. Rebuild immediate Tier-B context on the same footprints: four deterministic variants, restrained Asok/Sathorn/riverside palettes, recessed structural shells behind visible window planes. Actual instanced rays check the four elevations; nominal hidden window pieces are insufficient.
8. Review fixed ordinary street/arrival, explicit elevated/river, sunset/night views. Keep weak/cropped views and label inspection overrides; hide no city geometry to manufacture evidence.
9. Run controller entrance/exit/interdistrict routes separately with traffic off/on. Verify camera reset/restart, map/inspection return, collisions, mission/save/discovery compatibility and retained-resource disposal.
10. Compare matched visible calls/triangles, memory, construction, texture/material counts and production bundle bytes. Certify physical Safari separately; software WebGL is not a hardware FPS result.
