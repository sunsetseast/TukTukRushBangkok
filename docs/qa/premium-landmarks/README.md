# PR35 — Bangkok hero architecture

Six active landmark builders are reconstructed: Terminal 21, ICONSIAM, MahaNakhon, Millennium Hilton, Peninsula and Mandarin Oriental. The work adds physically recessed entrances, distinct street/river fronts, authored silhouettes, opaque architectural glazing, selective night illumination and bounded tropical planting. The existing architecture grammar also improves 103 nearby parcels without changing their footprints.

Start with the [matched WebGL gallery](gallery.md), [critical visual scorecard](scorecard.md) and [performance review](performance.md). These show the rendered result and its limitations, rather than treating geometry counts as art quality.

The authoritative `bangkok-arcade-2026.1` road graph, landmark IDs, origins/yaws, destination access nodes, river, BTS/MRT and all original 208 protected parcels remain intact. One researched, explicitly bounded Terminal east pedestrian apron is added to canonical city data: four obstructing shop footprints become three smaller side parcels, leaving 7,086 buildings and 209 protected parcels. This is an arcade frontage adaptation, not a surveyed legal vehicle gate. Approval hashes are not changed.

The draft is suitable for inspection of implemented code and evidence. It does **not** certify every production acceptance gate: exact property gates/curbs and some coordinates remain unresolved; ICONSIAM's complete development/plaza scale and MahaNakhon's Cube precinct remain follow-ups. Physical iPhone 17 Pro Max Safari testing and an independent human art/geography review remain outstanding. No merge or deployment is part of this work.
