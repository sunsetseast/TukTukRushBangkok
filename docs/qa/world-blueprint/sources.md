# Source and photographic reference library

- [Geofabrik Thailand](https://download.geofabrik.de/asia/thailand.html): investigated the country extract; used eight smaller [OSM API](https://wiki.openstreetmap.org/wiki/API_v0.6) bounding boxes instead of importing a whole country. Published stripped derivatives contain 2,432 named corridor features and 1,206 place facts. Object URLs, retrieval URLs, UTC timestamps and raw-response SHA256 hashes are recorded in `sources/`. Way points are arithmetic vertex centroids, not surveyed entrances.
- [OSM copyright and attribution](https://www.openstreetmap.org/copyright): derived research database supplied under ODbL 1.0, © OpenStreetMap contributors. See [database README](../../../data/bangkok/README.md). Contributor metadata is excluded; no restricted Google Maps/Street View data is extracted. The playable graph remains authored arcade geometry.
- [Overture documentation](https://docs.overturemaps.org/) and [theme-specific attribution/licensing](https://docs.overturemaps.org/attribution/): stable identity/schema approach evaluated; no Overture dataset imported and no blanket licence assumed.
- BMA GIS, City Planning and district ArcGIS portals were investigated. Geometry retrieval was unavailable/timed out. No BMA geometry is claimed as retrieved or used.
- [BTS operator map](https://www.bts.co.th/eng/routemap.html): represented station order and existing three-line scope retained. Station omissions require explicit operator review; numbering alone does not establish service.
- BEM [Sanam Chai BL31](https://metro.bemplc.co.th/Line-Maps?Line=2&Station=31), [Sam Yot BL30](https://metro.bemplc.co.th/Line-Maps?Line=2&Station=30), [Wat Mangkon BL29](https://metro.bemplc.co.th/Line-Maps?Line=2&Station=29): identity and historic street/access context checked. Game canopies are compressed sidewalk representations, not surveyed exit locations. MRT remains underground.
- [Museum Siam / National Archives Tha Tien](https://museumlinks.museumsiam.org/view-resource.php?l_id=67): two-storey European-influenced market frontage, pitched roofs, river access and commercial adaptation guide the secondary benchmark. The complete historic market plan is not replicated.
- [Hua Seng Heng operator contact](https://www.huasengheng.com/en/contact/): primary search results identify distinct Yaowarat branches; direct page fetch returned 403. No logo is newly imported or real branch assigned to arbitrary generated shops.
- [React Three Fiber scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance): resource reuse, instancing and distance detail. Installed official Three.js source supplies the technical implementation basis; the older optimize-lots-of-objects manual URL returned 404.

Licensed photographs are inspected from the existing [PR31 author/licence library](../landmark-accuracy/references/ATTRIBUTION.md): Ninara's Yaowarat night photograph (CC BY 2.0), Marcin Konsek's Chinatown Gate photograph (CC BY-SA 4.0), and the individually credited landmark/hotel references. Tha Tien uses Weerayas' `ถนน.JPG` (CC BY-SA 3.0), credited in [PR33 sources](../historic-visual-fidelity/sources.md).

The permanent inventory retains individual operator/architect references for hotels and major sites. Inherited links do not mean every property was independently photographically certified in PR34. Operator images without redistribution licences are linked only. Photos are QA references, not runtime textures. Dates and viewpoints limit direct comparisons. No AI-generated implementation screenshots are used.

Final inventory review uses exact reviewed name aliases and feature-type checks. Piers named after Wat Pho, Santa Cruz, Memorial Bridge and Phra Pinklao Bridge cannot supply temple/church/bridge coordinates; a hotel cannot inherit a museum match. The stricter cross-check leaves **83/138** records with approximate coordinates and **55** unresolved, rather than asserting false precision. See the reproducible inventory script and canonical QA guard.

The future-station legend resolves N6 as an intentional playable omission; see [transit review](transit-review.md).
