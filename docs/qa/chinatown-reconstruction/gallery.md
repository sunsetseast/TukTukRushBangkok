# Actual WebGL before/after gallery

All images are actual Chromium/SwiftShader WebGL application renders, medium quality,844×474 DPR1. Sunset elapsed40s; night650s. Traffic is disabled for matched art inspection. No generated illustrations or composited replacement scenery are used. Camera/target data and raw renderer samples are in before/capture.json and after/capture.json. The baseline is clean PR37; final images use the implemented game.

Street-level cameras follow the migrated same named corridor where the old road no longer occupies its original position; those paired coordinates are explicitly recorded as `afterCamera`/`afterLook` in scenes.json. Elevated/landmark comparison cameras retain identical world coordinates. These are equivalent viewing purposes and optics, not a claim every pair has identical world coordinates.
