# A–F visual recognizability scorecard

A means strong recognizable likeness with convincing composition; B means recognizable arcade interpretation with visible simplification; C means useful structure/character with material likeness limitations; D weak, E inadequate, F absent/broken. This is an internal source-and-screenshot assessment, not an independent Bangkok-resident panel. A driving grade refers only to the certified controller cases. No overall A is claimed merely because tests pass.
