# Paired actual game screenshot gallery

Both revisions use 960×540 medium graphics. Only the HUD is hidden; no city geometry is suppressed. Traffic is disabled for static inspection. The five `driving` views use the ordinary chase camera from a public-road position; other views use fixed inspection cameras. Street and driving positions are validated against the shared road graph. Reference photography is separately labelled in [comparisons](comparisons.md).
