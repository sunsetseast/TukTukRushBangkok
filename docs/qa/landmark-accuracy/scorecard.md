# Landmark quality scorecard

A = excellent; B = good with minor refinements; C = incomplete with important inaccuracies; D = poor with significant problems; F = broken. A dash means the location has not received an individual visual grade. Collision and ray tests do not determine these grades.

The registered-place inventory has 92 entries. The scorecard adds one Yaowarat street-view case. Thirty-one paired capture locations comprise 30 scene landmarks and the street case; embedded sub-places and other entries remain explicitly ungraded.
