# Real world and actual game comparisons

Reference photographs are real photographs under the licences listed in [attribution](references/ATTRIBUTION.md). Game frames are actual Chromium/WebGL captures, with no generated imagery. Angles and dates vary; a reference is not a surveyed reconstruction. Street observers are snapped to real playable roads. River-facing frames are inspection cameras; normal driving views use an on-road tuk-tuk.
