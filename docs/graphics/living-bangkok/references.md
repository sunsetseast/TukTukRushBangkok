# Research and asset provenance

Research informed rendering trade-offs and district character; no reference artwork, photographs, logos, meshes or textures were copied into the game.

| Primary source | Applied principle |
| --- | --- |
| [Three.js: color management](https://threejs.org/manual/en/color-management.html) | Albedo is sRGB; packed roughness/metalness and tangent normals are linear data. Vertex colors remain linear. |
| [React Three Fiber: scaling performance](https://r3f.docs.pmnd.rs/advanced/scaling-performance) | Reuse resources, bound animation work, use instancing and on-demand rendering for the paused map. |
| [Three.js: optimizing many objects](https://threejs.org/manual/en/optimize-lots-of-objects.html) | Keep existing spatial batches instead of introducing a mesh per architectural ornament. |
| [Khronos: mesh quantization](https://github.com/KhronosGroup/glTF/blob/main/extensions/2.0/Khronos/KHR_mesh_quantization/README.md) | Four-byte alignment for packed three-component vertex vectors informs the static attribute layout. |
| [Three.js: shadows](https://threejs.org/manual/en/shadows.html) | Prefer bounded ground projections over rendering thousands of casters into dynamic shadow maps. |
| [MDN: WebGL best practices](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API/WebGL_best_practices) | Budget resident resources and uploads; avoid synchronous GPU queries and expensive postprocessing. |
| [Tourism Authority of Thailand: Talat Noi](https://www.tourismthailand.org/Articles/1-day-in-talat-noi) | Older community/workshop and warehouse vocabulary, retained alongside the existing riverfront geography. |
| [Tourism Authority of Thailand: Chinatown](https://www.tourismthailand.org/Articles/the-adventure-through-bangkok-s-chinatown) | Layered commercial streets and food activity; preserve the authored Sino-Thai signage rather than distributing lanterns everywhere. |
| [Tourism Authority of Thailand: Khao San Road](https://thai.tourismthailand.org/Attraction/ถนนข้าวสาร) | Guesthouse, clothing, restaurant and evening-light vocabulary distinct from Yaowarat. |
| [Tourism Authority of Thailand: Grand Palace](https://www.tourismthailand.org/Attraction/the-grand-palace) | Preserve the established temple/royal silhouettes and precincts, rather than rebuilding successful landmarks. |
| [BTS: system design](https://www.bts.co.th/eng/library/system-design.html) | Keep the elevated railway, stations and pedestrian approaches coherent with the existing transport model. |

The game remains a compressed, stylized Bangkok. Added facades, warehouse bays, shop contents, shutters, service equipment and lighting are original artistic interpretations, not dimensioned architectural replicas or assertions about individual real tenants. Existing destination entrances remain authoritative.

## New assets

All new atlas pixels, road grain, paving shading, sky shading, architectural modules, character accessories and vehicle details are generated by code in this repository. The facade set uses deterministic 128×128×8 color, PBR and normal texture arrays (the texel budget of three 512×256 sheets); asphalt uses a small original procedural texture. There are no newly downloaded bitmap assets, GLBs, external fonts, licensed game artwork or remote decoder dependencies. They inherit the repository's license. Existing fonts/assets and their notices are unchanged.

No app dependency or lockfile change is required. KTX2/Basis was considered but not added: these small, locally generated atlases do not justify a decoder/download pipeline, while static geometry attributes were a much larger measurable cost. Texture compression remains a possible future choice if a substantial authored texture library is introduced.
