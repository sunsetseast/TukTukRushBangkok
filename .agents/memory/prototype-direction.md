name: Prototype direction
description: User's device constraints, map direction and priority order for the arcade driving prototype
---
The user develops and tests entirely on iPhone. Touch is the primary supported gameplay input; keyboard is only a development convenience.

The user wants a hybrid Bangkok map with real major roads and landmarks plus fictional arcade-friendly shortcuts, and colorful 3D graphics.

For the first playable, the priority order is running 3D gameplay and reliable iPhone controls, fun handling, end-to-end missions, believable hybrid road layout, performance, then environmental polish. This phase is browser-based, not native iOS or TestFlight.

**Why:** The user explicitly stated these constraints and priorities.

**How to apply:** Keep the creator's workflow usable on iPhone; do not require desktop-only testing steps from them. Preserve the hybrid map direction and prioritize responsive, stable controls over realistic three-wheel instability or decorative features.
